Privacy Policy

Effective Date: August 13, 2026

This Privacy Policy describes how the 2026 Fantasy Draft Assistant Chrome extension and associated web application ("we", "our", or "us") handle user data.

1. Single Purpose

The single purpose of the 2026 Fantasy Draft Assistant extension is to provide live fantasy football draft recommendations, team grade analysis, and custom ranking overlays directly within active draft rooms on supported platforms (such as Sleeper and ESPN).

2. Data Collection & Processing

We are committed to user privacy. The extension operates with the following data parameters:

  • Page Content: The extension reads active draft room DOM elements (e.g., player names, pick numbers, roster slots) strictly to render real-time UI overlays and recommendations. This data is processed locally in your browser and is never stored on external servers or sold.
  • User Preferences: Preferences such as overlay toggle states and account settings are stored locally on your device via chrome.storage.local.
  • Account Data: If logged into an account on our rankings platform, authentication token and saved board rankings are retrieved via secure API to sync your custom rankings with the draft assistant.

3. Data Sharing & Third Parties

We do not sell, trade, rent, or transfer any user data or personal information to third parties. All draft interactions occur strictly inside the user's browser environment.

4. Use of Permissions

  • activeTab & tabs: Used to detect active fantasy draft rooms and toggle the assistant overlay.
  • storage: Used to save UI states and user preferences locally.
  • scripting & Host Permissions: Used to render draft assistant UI elements directly inside draft room pages.
